# Datasheet — BBO Capstone Query and Evaluation Dataset

Confirmed portal responses are available through **Week 11**. Week 12 queries
have been selected but their outputs are not yet confirmed.

The dataset consists of initial course observations plus one sequential
query/output pair per function per completed round. Functions range from 2D to
8D.

Week 12 adds PCA diagnostics over standardised observed inputs. PCA is
interpretive only: its principal directions describe variance in the sampled
query distribution, not causal importance or the hidden global response
surface.

Sampling is sparse and increasingly concentrated around high-performing
regions, creating exploitation bias. Function 3 has also shown repeated-input
variability, indicating possible observation noise.
